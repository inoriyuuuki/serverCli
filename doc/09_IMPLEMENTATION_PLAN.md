# 分阶段实施计划与验收门禁

> 日期：2026-08-07  
> 原则：先测试、后实现、再远端验收；正式环境不作为开发试验场。

## 1. 实施原则

1. 每个阶段先补测试样例和验收脚本，再写实现。
2. 测试环境默认使用 `<test-server-ip>` 和 SQLite。
3. 主/子逻辑实例同机运行时必须隔离端口、state、日志和身份。
4. 完成测试环境端到端回归后，才准备正式 PostgreSQL 部署。
5. 所有远端操作和报告必须脱敏。
6. 每个阶段更新本文档和 [10_CHANGE_TARGETS.md](10_CHANGE_TARGETS.md)。

## 2. Phase 0：仓库骨架与工程基线

### 目标

- 建立后端、前端、命令、数据库迁移、部署和脚本目录。
- 确定 Go/React 或经确认的替代技术栈。
- 建立 CI、本地测试、格式化、静态检查和 Secret 扫描。

### 交付物

- 最小可启动前后端；
- `/health/live`、`/health/ready`、`/version`；
- 测试/正式非 Secret 配置模板；
- `scripts/start.sh` 等脚本接口骨架。

### 门禁

- 全新本地环境能构建；
- 配置缺失时安全失败；
- 测试脚本不含正式环境默认写操作；
- 仓库中无明文凭证。

## 3. Phase 1：数据库与简单账号

### 目标

- PostgreSQL/SQLite 双数据库迁移框架。
- 单管理员登录、退出、会话、改密和限流。
- 基础页面布局和环境标识。

### 测试

- 两种数据库运行相同 Store 合约测试；
- 密码哈希、会话过期、CSRF、Cookie 和失败限流；
- 初始化密码只使用运行时 Secret，完成后移除。

### 门禁

- 测试 SQLite 重启后管理员仍可登录；
- PostgreSQL 隔离测试通过；
- 认证事件进入审计。

## 4. Phase 2：节点注册与基础信息

### 目标

- 主/子 Agent 注册申请、审批、领取身份和心跳。
- 主节点唯一、子节点不可提升。
- 主界面基础信息和服务器列表。
- 主/子可见范围后端隔离。

### 测试

- 同一测试 IP 上两个实例获得不同 `node_id`；
- 复制 state、重复申请、重复领取和来源变化；
- 心跳丢失、离线、恢复和重启持久化；
- 子节点访问其他节点返回拒绝。

### 门禁

- 测试主 UI `9044`、API `9045`；子 UI `9046`、API `9047` 全部健康；
- 主视图显示两个逻辑节点，子视图只显示自己；
- SQLite 数据和两个 Agent state 无混用。

## 5. Phase 3：命令发现与任务执行

### 目标

- 命令 manifest、分类和参数 Schema。
- Agent 上报命令清单。
- 主节点创建任务、Agent 执行、流式事件和结果展示。

### 测试

- 合法/非法参数；
- 未登记命令、版本不一致和节点离线；
- 超时、取消、输出截断、并发限制；
- 幂等重试和结果未知；
- Shell 注入、路径逃逸和未批准 sudo 被拒绝。

### 门禁

- 至少三个无害命令完成主节点远程调用；
- 子节点本机 UI 可执行自己的命令；
- 所有任务有数据库记录和关联审计。

## 6. Phase 4：AI SSH Lease

### 目标

- AI 申请 API/Skill、临时公钥安装、1 小时默认 Lease。
- 自动/人工审批、自动续期、24 小时绝对上限。
- 正常断开撤销、异常断连清理、管理员禁止续期和紧急撤销。
- 活动凭证、申请记录和会话记录页面。

### 测试

- 幂等申请不重复安装公钥；
- 私钥不上传，长期密码不使用；
- 新申请/续期开关；
- 续期不超过首次签发 + 24h；
- 正常/异常断开；
- 撤销后禁止新连接；
- 强制终止开启时现有会话被终止；
- 节点重启后无过期 key 残留；
- 权限越权被拒绝。

### 门禁

- 在测试主、子逻辑节点分别完成端到端登录；
- Lease 状态、节点授权文件和活动进程一致；
- 全流程可通过 `lease_id/session_id` 查询审计。

## 7. Phase 5：审计、重要标记与清理

### 目标

- 统一审计模型；
- 重要记录保护；
- 默认每周、7 天可配置清理；
- dry-run、批量、安全删除和清理报告。

### 测试

- 构造保留边界前后数据；
- 时区边界；
- 重要记录不删除；
- 手动删除重要记录需要原因并审计；
- 清理失败可重试且不会重复破坏。

### 门禁

- 自动和手动清理均符合策略；
- 清理行为本身可审计；
- 日志和输出 Secret 脱敏抽查通过。

## 8. Phase 6：一键部署与正式发布准备

### 目标

- 从源码构建的一键启动/停止/状态/日志/迁移脚本。
- systemd 服务、开机自启、健康检查和日志轮转。
- 正式 PostgreSQL 备份恢复、升级和回滚。
- TLS、防火墙、账号和文件权限加固。

### 测试

- 全新测试环境重复部署；
- 服务和数据库重启恢复；
- 迁移失败回滚；
- 端口冲突和配置错误安全失败；
- 备份恢复演练；
- 完整回归：登录 → 节点 → 命令 → AI Lease → 审计 → 清理。

### 正式发布门禁

- 用户再次确认正式 IP 与 `9042/9043` 端口；
- PostgreSQL 备份可恢复；
- 受信任 TLS 可用；
- 已轮换部署阶段使用过的长期密码；
- `admin` AI profile 关闭或有明确批准；
- 回滚步骤已演练。

## 9. 建议任务拆分

| Epic | 任务 |
| --- | --- |
| 工程 | 目录、构建、配置、健康检查、CI |
| 认证 | 单管理员、会话、CSRF、限流、改密 |
| 数据库 | 双数据库、迁移、Store 合约、备份 |
| 节点 | 注册、审批、凭证、心跳、状态、信息采集 |
| UI | 布局、主/子菜单、概览、服务器页 |
| 命令 | Manifest、Schema、Agent 执行、任务状态机 |
| AI Lease | 申请、审批、key 安装、续期、撤销、会话守护 |
| 审计 | 统一事件、脱敏、查询、重要标记 |
| 清理 | 策略、计划任务、dry-run、手动删除 |
| 部署 | 一键脚本、systemd、TLS、正式发布 |

## 10. Definition of Done

一个功能只有同时满足以下条件才算完成：

- 需求 ID 有对应实现；
- 单元/集成测试通过；
- PostgreSQL/SQLite 相关行为均验证；
- 主/子权限隔离验证；
- 安全失败路径和审计验证；
- 文档、配置示例和运维步骤更新；
- 没有引入明文 Secret；
- 测试环境端到端验收通过。

## 11. 实施状态（2026-08-07 首轮实现）

> 以下为当前仓库已完成的实施状态，作为本计划的执行记录。

### 已完成

- **Phase 0 工程基线**：Go 后端（control-plane + node-agent）、React+Vite 前端、命令样例、SQL 迁移（内嵌+参考目录）、一键脚本、`.env.example` 模板、Makefile。
- **Phase 1 数据库与账号**：SQLite/PostgreSQL 兼容迁移（当前 2 个版本）；单管理员（Argon2id、HttpOnly Cookie 会话、CSRF、登录限流、改密、初始化密码运行时注入后清除）。
- **Phase 2 节点**：注册申请 → 审批 → 一次性领取身份 → 心跳；`pending/online/degraded/offline/disabled/rejected`；同 IP 多实例通过独立 `node_id`/端口/state 区分；主节点唯一；子节点后端强制本机作用域（动态随 Agent 领取身份生效）。
- **Phase 3 命令与任务**：YAML manifest、参数 Schema 最小校验、Agent 上报命令快照、长轮询领取、argv 执行、流式事件、幂等键、任务状态机、输出上限。
- **Phase 4 AI SSH Lease**：申请（幂等）、默认 1h、绝对上限 24h、续期/心跳/断开/撤销、全局与节点开关、断连宽限、临时公钥原子安装/删除（restrict 前缀）、`servercli-lease-shell` 包装器约定、管理员禁止续期/标记重要/紧急撤销全部。
- **Phase 5 审计与清理**：统一审计事件（含筛选）、脱敏、重要标记保护、默认每周/7 天可配置清理、dry-run、清理记录与清理审计。
- **Phase 6 部署脚本**：`start/stop/restart/status/logs/migrate/bootstrap-admin/smoke-test`；测试环境一键主+子同机运行；正式环境强制 `--confirm-production`；systemd 模板；SQLite 迁移前备份（正式 PostgreSQL 需 `pg_dump`）。

- `./scripts/smoke-test.sh`（测试主 9044/9045 + 子 9046/9047）：31/31 PASS —— 健康检查、SPA、登录+CSRF、注册/审批、心跳、命令发现、任务执行、Lease 申请/续期/断开、审计、清理 dry-run、子节点作用域隔离、重启持久化。
