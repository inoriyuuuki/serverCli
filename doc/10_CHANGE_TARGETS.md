## 2. 相对历史项目基线的主要变动

仓库历史中曾存在一版已删除实现。本轮不会直接恢复旧代码，后续如重建应注意以下变化：

1. **端口发生变化**：当前正式前端/后端为 `9042/9043`，测试主为 `9044/9045`，测试子为 `9046/9047`。
2. **测试数据库变化**：当前明确要求测试使用本地 SQLite，而不是测试 PostgreSQL。
3. **测试拓扑变化**：当前测试主、子节点共用 `<test-server-ip>`，必须支持同 IP 多实例。
4. **部署方式强调源码运行**：一键脚本需要构建源代码，不以仅拉取预制镜像为唯一方案。
5. **AI 凭证要求更明确**：正常断开自动失效、续期最长 24 小时、管理员禁续期、申请记录和重要记录保护都成为首版要求。
6. **清理要求更明确**：默认每周执行、保留时间可配置、重要记录不自动删除。

## 3. 已做出的安全性设计解释

### 3.1 为什么不能只用 IP 标识节点

测试主、子节点共用相同 IP；未来服务器也可能位于 NAT、容器或反向代理后。因此：

- IP 用于发现、连接和展示；
- `node_id` 用于数据库关系、鉴权、任务和 Lease；
- 当用户以 IP 选择节点且匹配多个实例时，系统必须要求进一步选择端口/别名/节点 ID。

### 3.2 为什么不把 SSH 密码写入文档

密码一旦进入 Git 历史，即使后续删除仍可能被恢复。后续脚本应通过受保护的 Secret、交互输入或 SSH Key 获取运维权限。建议对已经在对话中提供的密码安排轮换。

### 3.3 为什么 AI 使用临时公钥

临时公钥可以独立撤销、限制权限、设置 TTL 和关联审计；长期密码无法安全分配给 AI，也不便区分不同申请和会话。

## 4. 实现前待确认事项

以下问题不阻止文档设计，但会影响最终实现：

1. **技术栈**：是否确认 Go + React/TypeScript；若已有偏好需在 Phase 0 前调整。
2. **子节点 Web**：正式子节点是否都必须单独开放前端/后端，还是仅运行 Agent、通过主节点统一管理。当前文档兼容两种方式。
3. **正式子节点端口**：尚未给出；建议按节点配置，且 Agent 主动连接可避免开放管理端口。
4. **节点注册审批**：默认建议“申请后管理员批准”；是否允许一次性引导 Token 自动批准。
5. **AI 审批**：测试默认策略自动批准低风险，正式默认人工；需确认。
6. **撤销语义**：是否强制终止已经建立的 SSH 会话。当前设计支持并建议正式启用。
7. **AI 权限清单**：`read-only/operator/admin` 分别允许哪些命令、文件、sudo 和网络访问。
8. **交互式 Shell**：AI 必须拥有完整交互式 shell，还是受控命令接口即可。完整 shell 的审计和隔离成本更高。
9. **自动断连宽限**：当前建议 60 秒，需根据 AI 客户端 heartbeat 频率确认。
10. **记录保留**：用户明确默认 7 天；任务元数据、AI 申请和 Lease 历史是否也统一 7 天，还是采用文档建议的 30 天。
11. **终端录像**：是否需要；若需要，应确认知情提示、访问权限、脱敏和容量。
12. **TLS 与访问范围**：是否有域名和证书，Web/API 是否公开公网，是否增加 VPN/IP 白名单。
13. **正式 PostgreSQL**：数据库部署位置、备份目标、恢复目标时间和容量预估。
14. **部署托管**：源码构建后使用 systemd 是否可接受；是否还需要 Docker Compose 作为可选方式。

## 5. 推荐默认决策

若暂不补充，实施可采用以下默认值：

- Go + React/TypeScript；
- 主节点统一管理，子节点默认只运行 Agent，本机 UI 作为可选部署；测试子 UI/API 按给定 `9046/9047` 启用；
- 节点注册需要管理员批准；
- 测试 AI `read-only` 可策略自动批准，正式全部人工批准；
- 撤销 Lease 时强制终止存量会话；
- 断连宽限 60 秒；
- AI `admin` profile 关闭；
- 普通输出/会话日志 7 天，任务/申请/Lease 元数据 30 天，重要记录永久保留；
- systemd 托管从源码构建的二进制和前端静态文件；
- 正式强制 HTTPS，测试至少支持 TLS。

### 首轮实现相对文档的决策记录

1. Agent 与 Control Plane 之间使用 Bearer node credential + HMAC-SHA256 时间戳签名（契约 §4），不依赖 mTLS（测试环境）。
2. Control Plane 的 Lease 安装/删除指令通过心跳响应携带（`install/remove` 操作），避免单独推送通道；Agent 通过 `/agent/leases/{id}/events` 回执。
3. 子节点本机 UI/API 默认启用（测试子 9046/9047）；子控制面作用域随本地 Agent 领取身份后动态刷新。
4. 控制面同时监听 `FRONTEND_ADDR`（浏览器 UI）与 `BACKEND_ADDR`（API/Agent），两者共享同一 handler。
5. AI 续期令牌只存哈希+前缀，申请成功时一次性返回给 AI 客户端。
6. 首版验收以测试环境 SQLite + 本地回环执行为准；正式 PostgreSQL/TLS/SSH 真机项列入发布前门禁。
