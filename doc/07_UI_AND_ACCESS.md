# 管理界面与访问范围

> 日期：2026-08-07

## 1. 页面总体布局

```text
┌──────────────────────────────────────────────────────┐
│ 环境标识 | 当前节点/集群 | 在线状态 | 管理员 | 退出     │
├───────────────┬──────────────────────────────────────┤
│ 左侧功能导航    │ 页面标题 / 筛选 / 操作                   │
│               │                                      │
│ 概览           │ 当前页面内容                           │
│ 服务器         │                                      │
│ 命令中心        │                                      │
│ 任务           │                                      │
│ AI 凭证        │                                      │
│ 审计日志        │                                      │
│ 系统设置        │                                      │
└───────────────┴──────────────────────────────────────┘
```

所有页面顶部持续显示：

- 环境：正式/测试，用明显颜色区分；
- 当前角色：主节点/子节点；
- 当前节点名称、IP 和 `node_id` 短标识；
- Control Plane、Node Agent 和数据库状态；
- 当前管理员会话剩余时间。

正式环境执行写操作时应额外显示正式环境确认提示。

## 2. 主节点导航

### 2.1 概览

默认展示主服务器本机基础信息，同时显示集群摘要：

- 主节点信息卡；
- 节点总数、在线/离线/待审批数量；
- CPU、内存、磁盘、负载和运行时间；
- 最近失败任务；
- 活动 AI Lease 与即将到期 Lease；
- 高风险审计事件；
- 清理任务和数据库状态。

### 2.2 服务器

- 节点列表：名称、角色、IP/端口、状态、版本、最近心跳、资源摘要。
- 待审批申请：来源地址、主机名、申请角色、Agent 版本和风险提示。
- 节点详情：基础信息、地址、能力、任务、Lease、审计和设置。
- 操作：批准、拒绝、禁用、修改别名/标签、轮换节点凭证。
- 删除：仅离线/停用的子节点显示「删除」；输入完整 `instance_name` 二次确认后永久级联删除（任务、Lease、免审批规则、参数历史、指标、审计），主节点与在线节点不可删除。

### 2.3 命令中心

- 按分类、节点、权限配置筛选命令；相同命令（command_id + version + 兼容 Schema/权限/超时）合并为一行展示支持节点数。
- 执行时多选目标节点，并行提交各节点任务（每个节点独立幂等键），展示各节点成功/失败结果。
- 根据参数 Schema 自动生成表单；弹窗内展示该命令在各目标节点的历史参数，可一键回填（含敏感字段）或删除记录（不影响原任务）。
- 提交前展示目标节点、命令版本、超时、权限和参数预览。
- 高风险命令要求二次确认和填写原因。

### 2.4 任务

- 展示任务 ID、节点、命令、发起者、状态、耗时和时间。
- 任务详情展示时间线、参数脱敏摘要、stdout/stderr、退出码和审计关联。
- 支持取消可取消的运行任务、保护记录、按条件清理。

### 2.5 AI 凭证

建议拆为四个页签：

1. **活动凭证**：Lease 状态、目标节点、AI、权限、签发/到期、剩余时间、续期次数、活动会话。
2. **申请记录**：全部申请、审批/拒绝结果、原因、公钥指纹和来源；待审批申请支持「批准并免审批」（选择 1–15 天）。
3. **自动免审批**（主节点）：设备+节点规则列表，展示到期时间、剩余时间、状态；支持「延长」（已过期规则可重新激活）。
4. **控制策略**：全局/节点的新申请开关、续期开关、默认时长、自动审批规则和紧急撤销。

活动凭证操作：

- 禁止单个 Lease 续期；
- 撤销 Lease；
- 撤销并终止会话；
- 标记重要；
- 查看会话和操作记录。

### 2.6 审计日志

筛选条件：

- 时间范围；
- 节点；
- 操作者类型和 ID；
- 动作；
- 资源类型；
- 成功/拒绝/失败；
- 风险等级；
- `request_id/task_id/lease_id/session_id`；
- 是否重要。

详情以结构化字段展示，Secret 必须已在服务端脱敏。

### 2.7 系统设置

- 心跳间隔和离线阈值；
- AI Lease 默认时长、最大时长和断连宽限；
- 自动审批策略；
- 命令并发、超时和输出上限；
- 数据保留和每周清理计划；
- 管理员修改密码；
- 系统版本和数据库迁移版本。

Secret 和服务器长期密码不在页面中展示或编辑。

## 3. 子节点导航

子节点只显示：

- 本机概览；
- 本机命令；
- 本机任务；
- 本机 AI 凭证；
- 本机审计；
- 受限本机设置。

不显示：

- 其他节点；
- 集群全局统计；
- 节点审批；
- 全局 AI 策略；
- 其他节点任务和审计；
- 正式数据库配置。

后端必须把子节点认证上下文绑定到本机 `node_id`。即使请求中手工替换 URL，也应返回 `403` 或 `404`，不能泄露其他节点是否存在。

## 4. 页面状态

每个页面必须区分：

- 初始加载；
- 空数据；
- 权限不足；
- 节点离线；
- 后端不可达；
- 数据库不可用；
- 部分数据过期；
- 操作失败；
- 操作结果未知。

不得把“加载失败”显示成“没有数据”。

## 5. 账号与会话体验

- 未登录只能访问登录页和健康检查。
- 登录成功跳转到概览。
- 会话过期时清理本地状态并返回登录页。
- 修改密码后可选择撤销其他会话；首版建议撤销全部旧会话。
- 登录失败不明确提示“用户不存在”还是“密码错误”。
- 连续失败触发短时限流，并记录审计。

## 6. 高风险操作确认

以下动作要求二次确认并填写原因：

- 正式环境高风险命令；
- 启用 `admin` AI 权限；
- 紧急撤销全部 Lease；
- 终止活动 SSH 会话；
- 删除重要记录；
- 修改数据保留策略为更短时间；
- 禁用主节点或轮换主节点凭证；
- 永久删除服务器节点（输入实例名确认）；
- 批准并创建设备+节点免审批规则。

## 7. 可访问性和响应式

- 状态不能只通过颜色表达，需配合文字/图标。
- 表格支持键盘导航、固定表头和窄屏横向滚动。
- 时间同时提供本地显示和 UTC 悬浮提示。
- 输出窗口支持等宽字体、复制脱敏内容和下载权限控制。
